# Resistencia_Criptografica_LM_GLM_CBPSO
Código utilizado para el artículo "Resistencia Criptográfica del Mapa Logístico Simple y Generalizado con Acoplamiento".

Facultad de Física, Universidad de Costa Rica. Propiamente, las gráficas y los datos del informe final provienen de CBPSOResultados.ipynb y GraficasECM.ipynb. 

Adicionalmente, antes de implementar CBPSO, se realizaron dos pasos previos: la creación de un algoritmo PSO básico sobre la función de Rosenbrock, y la recreación del artículo de Sheludko (2022) para el mapa logístico simple, pero utilizando un peso de inercia con forma de función exponencial. Con esto, se logró luego construir el proceso completo de CBPSO de interés para el proyecto.

La graficación de los parámetros y el ataque caótico fueron empleados en secciones por aparte por tipo de mapa, mientras que el criptoanálisis diferencial comparativo fue realizado en conjunto.
